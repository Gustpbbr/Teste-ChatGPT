📊 1. Visão Geral do Ecossistema

O que é o Gus?

Um organismo cognitivo pessoal com 3 camadas:

  • Corpo (VR/WebXR): Three.js, interface espacial, hand tracking
  • Alma (Hub Qdrant): Memória persistente, schema gus-18, curador híbrido
  • Sentidos (ACEE/gus_sense): Sensores wearable, gateway, interocepção

Tese central

"Memória é o centro; o modelo é descartável." A identidade do Gus vive no grafo de memória (Qdrant), não no LLM. Isso permite trocar de modelo sem perder identidade — uma arquitetura que antecipou tendências de 2026 (Letta, Mem0, Zep).

Princípios

  • Degradação em camadas (falha parcial > falha total)
  • Anti-memória-lixão (curadoria, staging, maturidade)
  • Local-first para dados sensíveis (LGPD/GDPR)
  • Fail-closed: na dúvida, não faz

🏠 4. MASE — O Dispositivo

O que é

Dispositivo multissensorial cilíndrico (~30cm altura) que serve como casa física do Gus. Integra projeção de imagem em névoa, áudio direcional, sistema olfativo (chips termoativos), câmera com tracking, plataforma giratória, sensores e IA embarcada. Governado por uma IA afetiva local (ACEE → Gus → MASE).

Fase 0 — Objetivo

Provar que o Gus funciona offline com IA local (Gemma 1B/4B via Ollama).

  • Métrica: Resposta coerente em PT-BR, com identidade Gus, sem internet
  • Modelo: Gemma3:1b (815 MB) ou Gemma3:4b (2.5 GB)
  • Latência: 3–8s no S20 (com NPU), ~29s em servidor CPU-only

📱 6. Galaxy S20 — Guia de Instalação

Instalação Simplificada (2 passos)

  1. Instalar Termux do F-Droid: https://f-droid.org/packages/com.termux/
    ⚠️ NÃO usar a versão da Play Store (abandonada)
  2. No Termux, colar:
curl -sL https://raw.githubusercontent.com/Gustpbbr/Teste-ChatGPT/organizacao-autoclaw/MASE/setup.sh | bash

O instalador detecta RAM e escolhe o modelo ideal automaticamente.

Depois de instalado

# Modo terminal
bash ~/gus-local/iniciar.sh

# Modo web (abrir no Chrome: http://localhost:8080)
bash ~/gus-local/iniciar_web.sh
